# 巴菲特价值投资买入前 Checklist

对 $ARGUMENTS 执行巴菲特价值投资买入前 Checklist 分析。

**支持输入格式**：单个或多个公司，用逗号/顿号/空格分隔。例如：`腾讯, 茅台, 英伟达` 或 `NVDA AAPL MSFT`

## 执行流程

### 第一步：解析输入，识别所有待分析公司

从 $ARGUMENTS 中解析出所有公司名称/代码。对每家公司确定：
- 公司全称、股票代码、上市交易所
- 如果公司未上市，标记为"未上市"并给出简要说明（是否有间接投资途径），跳过完整Checklist

### 第一步半：AI研究偏见预警

对每家公司进行"信息丰富度"快速评级（A/B/C），并在报告中标注：

| 等级 | 判断标准 | 对Checklist的影响 |
|------|---------|-----------------|
| A级 | 上市多年、数据充裕 | 正常执行，但警惕"共识陷阱"——所有指标看起来都清晰不代表真的确定 |
| B级 | 数据有限需推算 | 每个推算指标标注置信度，"好生意"判断加权考虑数据可靠性 |
| C级 | 信息极度稀缺 | 不勉强填满六关表格，诚实标注"数据不足无法判断"，聚焦可验证的核心问题 |

**核心原则**：Checklist的目标是**排除坏选择**。对于C级公司，"数据不足"不等于"不通过"，也不等于"通过"——应诚实标注为"灰色地带，需补充一手信息"，而不是因为AI无法填满表格就判为否决。

段永平说过："看不懂"有两种——一种是生意太复杂真的看不懂，一种是你还没花时间去看。AI研究的局限是容易把"资料少"和"看不懂"混为一谈。

### 第二步：并行数据收集

使用 Task 工具为**每家公司**启动独立的后台 Agent 进行数据收集（所有公司同时并行启动），每个Agent负责收集：

1. **盈利能力**：ROIC(없으면 ROE와 순부채/EBITDA, 5년 추이)、毛利率与同业中位数、营业利润率、FCF(5年)、FCF/净利润、SBC/매출
2. **估值数据**：当前股价、市值、정상화 FCF(3년 평균)、10年国债收益率、PE(TTM)、前瞻PE、PB、股息率
3. **增长趋势**：近3年收入/利润增速
4. **财务健康**：负债水平、资本开支需求、现金储备、净现金/净负债
5. **竞争格局**：市场份额、主要竞争对手、份额变化趋势
6. **护城河证据**：品牌/转换成本/网络效应/规模效应/技术壁垒的具体证据
7. **管理层记录**：CEO履历、关键决策、持股、资本配置记录
7½. **대주주·지배구조**：최대주주+특수관계인 지분율(5년 추이), 경영진 개인 지분, 주식담보 비율, 최근 3년 대주주 매매, 자사주 매입·소각 내역, 배당성향, 물적분할·중복상장 이력, 오너 일가 관련 내부거래, 승계 진행 여부 (한국: DART 최대주주 현황·임원 소유 보고·대규모기업집단 공시 / 미국: Proxy·13D/13G·Form 4)
8. **最新动态**：近6个月重大事件（业绩、并购、监管、管理层变动等）

### 第三步：逐公司执行六关 Checklist

#### 第一关：我能理解这门生意吗（能力圈）

必须回答：
- [ ] 能用一句话说清楚这家公司靠什么赚钱吗？
- [ ] 10年后大概率还在做什么生意？
- [ ] 哪些关键变量决定成败？

**评分标准**（★1-5）：
- ★★★★★：商业模式极其简单清晰，10年确定性高（如茅台：酿酒卖酒）
- ★★★★☆：模式清晰但有技术门槛，需要一定专业知识理解
- ★★★☆☆：模式可理解但10年确定性不高，行业变化快
- ★★☆☆☆：业务线复杂或行业剧变中，难以预判未来
- ★☆☆☆☆：完全不在能力圈内

**硬性否决**：如果连赚钱方式都说不清，直接标记为"不在能力圈，不做分析"。

**대주주 지분과 주주 정렬** (2026-11-15 추가)

대주주 구조는 "대주주가 소액주주와 같은 방향으로 주가 상승을 원하는가"를 보는 항목이다. 지분율과 기업가치의 관계는 일률적이지 않다는 연구가 있다(예: Morck·Shleifer·Vishny 1988은 내부자 지분이 낮은 구간에서는 가치와 같은 방향, 높은 구간에서는 경영 참호화로 반대 방향일 수 있다고 보고). 아래 구간은 이 스킬의 **작업 기준(관점)**이며 사실 명제가 아니다.

| 검사 항목 | 기준 | 이 회사 | 판단 |
|---|---|---|---|
| 최대주주+특수관계인 지분율 | 30~50%: 정렬과 견제가 균형 / 20% 미만: 경영권 방어 비용·책임감 약화 우려(미국식 분산 소유+성과연동 보상이면 예외) / 70% 이상: 유통주식 부족, 소액주주 견제력 약함 | | |
| 경영진 개인 지분 | CEO·핵심 경영진이 연봉의 몇 배를 이 회사 주식으로 보유하나 (많을수록 가점) | | |
| 지분 위치 | 오너 일가가 이 회사를 직접 보유하나, 지주사를 거쳐 낮은 지분으로 지배하나 (실질 지분이 낮을수록 이 회사 주가보다 다른 곳의 이익을 챙길 유인이 커짐) | | |
| 최근 3년 매매 | 대주주·임원 장내 매수 = 가점 / 대량 매도·블록딜 = 감점 | | |
| 주식담보 | 대주주 보유 주식 중 담보 비율 30% 초과 = 감점 (주가 급락 시 반대매매) | | |
| 내부거래 | 오너 일가가 따로 지분을 가진 회사와 거래 비중 10% 초과 = 감점 | | |
| 쪼개기 상장 | 최근 5년 핵심 사업 물적분할 후 자회사 상장, 또는 계획 = 감점 | | |
| 주주환원 | 자사주를 사서 **소각**하나(가점), 사서 쌓아두기만 하나(감점) / 배당성향과 그 추세 / 밸류업 계획 공시 여부 | | |
| 승계·상속 | 승계 진행 중이면 방향을 적는다: 상속세 부담 때문에 주가를 낮게 둘 유인, 또는 상속세 재원 마련을 위해 배당을 늘릴 유인 — 어느 쪽 증거가 있는지 | | |

반대 논거도 함께 적는다: 지분율이 높아도 소액주주를 존중한 이력이 있으면 문제가 아니고, 지분율이 적정해도 내부거래·쪼개기 이력이 있으면 정렬되지 않은 것이다. **숫자보다 이력이 우선한다.**

**评分标准**（★1-5）：
- ★★★★★：创始人掌舵、资本配置卓越、利益完全一致（대주주 감점 항목 0개, 자사주 소각·꾸준한 환원 이력）
- ★★★★☆：管理层优秀但有小瑕疵
- ★★★☆☆：管理层合格但有治理隐患（대주주 감점 항목 2개 이상이면 최대 ★3）
- ★★☆☆☆：有诚信或治理问题（쪼개기 상장·불공정 합병비율 등 소액주주 피해 이력이 있으면 최대 ★2）
- ★☆☆☆☆：严重诚信问题（→硬性否决）

#### 第五关：价格是否足够便宜（安全边际）

버핏처럼 '주주이익(FCF)'을 국채 금리와 비교한다. PER 배수는 참고만 한다. **계산은 도구로 한다.**

```bash
python3 tools/financial_rigor.py verify-market-cap --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}
python3 tools/financial_rigor.py calc --expr '{FCF 수익률·내재가치 계산식}'
python3 tools/financial_rigor.py three-scenario   --price {股价} --eps {EPS} --shares {股本亿}   --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE} --currency {币种}
```

| 지표 | 값 | 기준 | 판단 |
|------|------|---------|------|
| FCF 수익률 (정상화 FCF ÷ 시가총액) | | 일회성 항목을 뺀 3년 평균 FCF 사용 | |
| 장기 성장률 가정 | | 최근 5년 주당 FCF 성장률과 업종 성장률 중 낮은 값, 최대 연 6% | |
| **기대수익률 = FCF 수익률 + 장기 성장률** | | 10% 이상이면 매수 검토, (10년 국채 금리 + 4%p) 미만이면 비쌈 | |
| PER(TTM·예상), PB, 배당수익률 | | 과거 5~10년 범위에서 어디쯤인지 참고 | |

**내재가치와 안전마진**:
- 내재가치 = 정상화 FCF × (1 + g) ÷ (r − g). 할인율 r = 10%(미국·한국 공통 기본값), g = 위 장기 성장률(단, r − g는 최소 5%p → FCF의 최대 약 20배).
- 낙관(g + 2%p), 중립, 비관(g − 3%p, 최저 0%) 세 경우를 계산한다.
- 필요한 안전마진: 해자 ★5·좋은 사업 ★5인 1급 회사는 내재가치보다 25% 이상 싸야, 그 밖의 회사는 33% 이상 싸야 매수. 4관에서 대주주 감점 항목이 2개 이상이면 필요한 안전마진에 5%p를 더한다(지배구조 할인).
- 이익·FCF가 적자면 이 계산을 하지 않고 PSR과 동종업체 비교로만 판단하며 ★2를 넘지 않는다.

추가 점검:
- 판단이 틀렸다면 지금 가격에서 최대 얼마나 잃는가? (비관 시나리오 기준)
- 주가가 반토막 나면 더 살 수 있는가?

**별점**(★1~5):
- ★★★★★: 중립 내재가치보다 50% 이상 쌈
- ★★★★☆: 필요한 안전마진(25% 또는 33%, 지배구조 할인 반영) 이상 확보
- ★★★☆☆: 내재가치 근처(±10%), 안전마진 부족
- ★★☆☆☆: 중립 내재가치보다 비쌈
- ★☆☆☆☆: 낙관 내재가치보다도 비쌈

### 第五步：快速否决清单

对每家公司逐条检查，触发任何一条直接标注为"否决"：

- [ ] 说不清楚这家公司怎么赚钱
- [ ] 连续3年自由现金流为负且看不到改善
- [ ] 管理层有诚信污点

## 输出格式要求

1. 每家公司独立成章，包含：六关评分表 + 核心数据表 + 关键风险（3-5条）+ 镜子测试 + 明确结论
2. 多公司时在最后附总览对比表
3. 所有评分必须使用★符号（★1-5），不含半星
4. 数据必须标注来源时间，估计值必须注明"估计"
5. 文末附结语，呼应巴菲特名言："投资的第一条规则是不要亏损"
6. 语言风格：直接、犀利、不说废话。用巴菲特/芒格/段永平的语录穿插点评

## 关键原则

- **宁可错过，不可做错**：Checklist的目标是排除坏选择，不是找到最好的
- **诚实面对能力圈**：看不懂就说看不懂，不要勉强分析
- **安全边际是生命线**：好公司买贵了也会亏钱
- **镜子测试不可跳过**：说不清楚理由就不买，没有例外
